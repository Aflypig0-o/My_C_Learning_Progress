# 通讯录管理系统

一个基于 C 语言实现的命令行通讯录，支持增删查改和文件持久化。

## 功能

- 添加联系人（姓名、电话、年龄）
- 显示所有联系人
- 按姓名查找
- 按电话查找
- 按姓名删除
- 按电话删除
- 按姓名修改
- 按电话修改
- 自动保存到文件
- 启动时自动加载

## 文件结构

- main.c      菜单和交互逻辑
- list.c/h    链表基础操作
- contact.h   联系人结构体定义
- file_io.c/h 文件读写
- Makefile    编译脚本
- contacts.txt 数据文件（运行时生成）

## 编译

    mingw32-make

## 运行

    mingw32-make run

或者直接运行:

    ./contact.exe

## 使用说明

启动后按菜单提示输入数字选择功能。

数据保存在 contacts.txt，格式为:

    name phone age

每行一个联系人。

## 技术要点

- 链表: 带头节点的单链表，尾插 O(1)
- 文件 IO: fprintf 写入，fscanf 读取
- 多文件编程: 按模块拆分
- 内存管理: 每个 malloc 都有对应 free
